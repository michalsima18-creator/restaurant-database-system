# Restaurant Database System

## 1. Project Overview

A relational database project focused on practicing SQL and database design using a restaurant management scenario. The project covers the design and implementation of a relational database, including data modeling, integrity constraints, relationships between entities, and database operations.

## 2. Technologies Used

- **SQL (Oracle Database)** – database creation, data manipulation, querying, and implementation of integrity constraints.
- **PowerDesigner** – conceptual and physical data modeling.

## 3. Database Design

The database represents a selected area of restaurant operations and consists of multiple related entities. The design includes a conceptual data model, relational schemas, and integrity constraints.

## 4. SQL Implementation

- **Table Creation** – creating database tables and defining their structure.
- **Integrity Constraints** – implementing primary keys, foreign keys, and other constraints.
- **Test Data** – inserting sample records into database tables.
- **Data Operations** – performing SELECT, INSERT, UPDATE, and DELETE operations.
- **User Privileges** – defining access rights for different database users.
